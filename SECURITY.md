# Security Policy

This repository is a fork of [ixartz/Next-JS-Landing-Page-Starter-Template](https://github.com/ixartz/Next-JS-Landing-Page-Starter-Template).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/ixartz/Next-JS-Landing-Page-Starter-Template/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
